This is a project that checks if the ISS(International Space Station) is above your head, given the provided lattitude and  longintude.
If the ISS isover your head and the sky is dark, it sends you a mail telling you to look up.

To run this application in your system:
    1. Create a app password in your gmail account and update "MY_EMAIL" and "MY_PASSWORD"
    2. Update "MY_LAT" and "MY_LONG" to your location specific latitude and longitude respectively
    3. To run the script in cloud use "pythonanywhere".
