Welcome to the Cafe REST API!

Endpoints:

  • GET /random - Get a random cafe
  • GET /all - Get all cafes
  • GET /search?loc=... - Search cafes by location
  • POST /add - Add a new cafe (requires form data)
  • PATCH /update-price/<id>?new_price=... - Update a cafe's coffee price
  • DELETE /report-closed/<id>?api-key=... - Delete a cafe
